# 员工照片批量处理工具（在线版）

在线地址：<https://banna-skech.github.io/photo-agent/>

上传员工原图后，在本地浏览器内完成 AI 抠图、纯白背景合成和厂家成品构图。照片不会上传到服务器。

## 校准后的成品规格

参数来自 `ref_0702_badge`、`ref_0717_badge`、`ref_0702_plate`、`0624座位牌` 和照片对比组的量化结果。

| 成品 | 文件规格 | 默认构图 |
| --- | --- | --- |
| 工牌照 | JPEG，1080×1440，144 DPI | 人像高度约 88%，底部贴边，裁到下腰/胯部 |
| 座位牌 | PNG，宽 700–800×高 900，144 DPI | 排除孤立抠图噪点，只按连续人体和手臂外缘紧凑取宽；人物居中且左右等量留白 |

两类成品均使用 RGB 纯白背景 `#FFFFFF`。`0702座位牌` 参考图统一换算到 900px 高后的宽度主要落在 700–800px（中位数约 740px），因此按手臂宽度在该区间内紧凑生成，不再固定为偏宽画布。边界识别仅保留最大连续人体区域，孤立灰点不会再把人物推偏。

## 使用方法

1. 等待页面提示“AI 抠图引擎已就绪”。
2. 上传或拖入一张或多张照片。
3. 点击“开始处理”。
4. 单独下载照片，或下载包含“工牌照”“座位牌”文件夹的 ZIP。

高级设置中的默认值已经按参考图校准，一般无需修改。

## 技术说明

- 纯前端 HTML、CSS、JavaScript，无后端。
- AI 抠图使用 `@imgly/background-removal`，在浏览器本地执行。
- JPEG 写入 144 DPI JFIF 密度信息。
- 座位牌使用 RGB PNG 编码，写入 144 DPI `pHYs` 信息且不含透明通道。
- GitHub Actions 自动部署 GitHub Pages。
