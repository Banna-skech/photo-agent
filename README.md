# 📸 员工照片批量处理工具

> 纯浏览器端运行 · 无需后端 · 无需安装 · 无需 API 密钥

上传员工原图 → AI 智能抠图 → 美白磨皮 → 自动输出工牌照 + 座位牌

## 🚀 部署到 GitHub Pages

### 第一步：创建仓库

1. 在 GitHub 上创建新仓库（例如 `photo-agent`）
2. 将本文件夹所有内容推送到仓库

```bash
git init
git add .
git commit -m "init"
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

### 第二步：启用 GitHub Pages

1. 打开仓库 → **Settings** → **Pages**
2. **Source** 选择 **GitHub Actions**
3. 推送代码后自动部署，URL 形如 `https://你的用户名.github.io/仓库名/`

### 第三步：分享链接

把 URL 发给同事，浏览器打开即用。照片处理完全在本地浏览器进行，不上传任何服务器。

## 🎯 功能

- **AI 智能抠图** — IMG.LY 模型，本地 WASM 推理
- **美白磨皮** — 可调节强度的皮肤柔化
- **双规格输出** — 工牌照 (上边距~11%) / 座位牌 (上边距~6%)
- **批量处理** — 多张照片依次处理，进度实时显示
- **一键下载** — 单张下载或打包 ZIP
- **隐私安全** — 所有照片在浏览器本地处理，不离开你的电脑

## ⚙️ 可调参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 工牌照上边距 | 11% | 头顶留白比例 |
| 座位牌上边距 | 6% | 比工牌照更紧凑 |
| 磨皮强度 | 30% | 皮肤柔化程度 |
| 美白提亮 | 6% | 肤色亮度提升 |

## 📐 输出规格

- 画布：1080 × 1440（3:4 竖版）
- 格式：JPEG（95% 质量）
- 背景：纯白 #FFFFFF

## 🔒 隐私说明

所有照片处理均在**你的浏览器本地**完成：
- 不上传任何服务器
- 不存储任何文件
- AI 模型从 CDN 加载到浏览器本地执行

## 🛟 故障排除

### AI 抠图不工作
- 检查网络是否能访问 `esm.sh` 和 `staticimgly.com`
- 刷新页面重试
- 即使 AI 不可用，工具仍可处理已有白底的照片

### HEIC 照片
- Safari 浏览器原生支持
- Chrome/Firefox 建议先用手机/系统工具转为 JPG
